# Web Application Security Assessment

## Project Overview
This project documents web application security testing completed during my cybersecurity internship using an authorized demo application.

## Tasks Performed
- Identified the target domain and checked connectivity.
- Scanned ports and identified running services.
- Identified web technologies and server information.
- Reviewed HTTPS certificate and security headers.
- Explored HTTP requests and responses using Burp Suite.
- Used Proxy, HTTP History, Repeater, Decoder, Comparer, and Site Map.
- Documented observations and security recommendations.

## Tools Used
- Kali Linux
- Nmap
- WhatWeb
- Nikto
- Burp Suite
- Firefox Developer Tools

## Learning Outcomes
Improved my understanding of web application assessment, HTTP traffic analysis, security configuration, and vulnerability documentation.

## Scope
Testing was performed on the authorized demo target demo.testfire.net. No exploitation or denial-of-service testing was performed.

This repository contains the project report and relevant screenshots of the work performed.
